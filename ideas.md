## Chosen Approach: Luminous Codex Workspace

### Design Movement
Afrofuturist Codex fused with contemporary digital atelier design.

### Core Principles
1. **Illumination over darkness:** Obsidian provides depth, while gold and emerald light guide attention; the interface must never become a flat black room or a sterile white sheet.
2. **Meaning before mechanics:** Semantic intent, living system state, and human purpose remain visible alongside implementation.
3. **Distinct fields, shared intelligence:** Research, design, code, architecture, and deployment each have their own visual expression while using one coherent interaction language.
4. **Presence without interruption:** Agents and teammates are visible as calm, accountable participants rather than noisy overlays.

### Color Philosophy
Obsidian is the ground of possibility; antique gold represents insight, authorship, and realized craft; emerald represents life, continuity, and safe flow; parchment and warm mist provide breathing room. The palette uses contrast as atmosphere rather than starkness.

### Layout Paradigm
A constellation layout: a persistent left project rail, a broad central live canvas, and a contextual right conversation loom. Content radiates from selected intentions rather than collapsing into a uniform dashboard grid.

### Signature Elements
- Gold and emerald orbit rings around active semantic nodes.
- Translucent parchment-glass cards with soft inner highlights.
- A small flame/orbit motif for active ideas, agents, and release states.

### Interaction Philosophy
Every action should reveal consequence. Selecting an object reveals its meaning, implementation, events, evidence, and agent history. Agents prepare before they execute. Simulation precedes release.

### Animation
Use slow breathing glows and event ribbons for ambient system life; use quick, tactile transitions for user actions; reserve larger motion for mode changes, simulation playback, and release moments. Respect reduced motion.

### Typography System
Display: Cormorant Garamond for poetic, authored headlines. Interface/body: Manrope for clarity. Technical values: JetBrains Mono for identifiers, event names, and code fragments.

### Brand Essence
Hael Studio is a living intelligence workspace for teams building meaningful systems across code, design, research, architecture, and deployment. Personality: **luminous, sovereign, generous**.

### Brand Voice
Headlines are concise and evocative. CTAs are direct, calm, and consequential. Microcopy explains what is happening without theatrical hype.

Example lines:
- “Bring an intention into the light.”
- “Simulate the change before it becomes real.”

### Wordmark & Logo
Use the provided gold-and-green flame/orbit symbol as the primary mark. The wordmark should sit beside it in a refined, letter-spaced serif treatment rather than a default UI font.

### Signature Brand Color
**Hael Emerald — `#6BAF63`**, used as the ownable life signal against obsidian and brass.

## Style Decisions

- Canvas fields must contain a visible codex layer: orbital geometry, manuscript-like guide structure, or symbolic node ornament behind semantic cards.
- Parchment light is a required counterweight to obsidian; reading surfaces and selected states should feel warm and manuscript-like rather than uniformly dark glass.
- The Hael wordmark is a crafted serif studio signature with deliberate letter-spacing beside the flame/orbit mark.
